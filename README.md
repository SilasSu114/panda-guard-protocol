# 熊猫卫士：逆转协议

现在先把最核心的“转一下世界，路就变了”跑通。画面还都是方块，先别被它劝退。

## 怎么跑

用 Godot 4.7 打开仓库里的 `project.godot`，然后点左上角的运行按钮，或者直接按 F5。

## 操作

| 按键 | 作用 |
| --- | --- |
| A / D | 左右移动 |
| W | 跳 |
| Space | 让场景顺时针转 90° |
| E | 和机关交互 |
| R | 重置当前关 |

## 现在做到哪儿了

- 玩家能走、能跳。
- 场景能按 90° 转一下。
- 开关、出口和提示已经能联动。
- 还没有存档，也没有死亡。
